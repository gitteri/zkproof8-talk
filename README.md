# zkproof8 talk — Confidential Transfers for Payment Orgs

25-minute talk for zkproof8 Rome, Day 2, 16:30. Speaker: Ilan Gitter, Solana Foundation.

The deck is a local Next.js webapp so it can host live demos against the
[`conf-balances-exploration`](../conf-balances-exploration) Rust backend.

## Run

```bash
pnpm install
pnpm dev          # http://localhost:3000 (or set --port)
```

Talk-day script:

```bash
# in another terminal
surfpool                     # provides ZK ElGamal Proof program for devnet parity

# in this terminal
pnpm dev --port 3000
open http://localhost:3000   # redirects to /s/1
```

## Keyboard

| Key | Action |
| --- | --- |
| `←` `→` `Space` | prev / next |
| `Home` `End` | first / last |
| `1`–`9` | jump to slide |
| `O` | overview |
| `P` | presenter notes |
| `B` `.` | blank screen |
| `Esc` | close overlays |

## Editing

- **`outline.md`** — narrative structure, time budgets, framing items still being decided.
- **`src/lib/slides.ts`** — slide registry. Titles, time budgets, presenter notes.
- **`src/slides/NN-name.tsx`** — one file per slide. Edit copy here.
- **`src/components/SlideFrame.tsx`** — shared `SlideFrame`, `SlideEyebrow`, `SlideTitle`.
- **`tailwind.config.ts`** — Solana brand palette and deck typography scale.

## Brand notes

Colors approximate the Solana brand:

- `sol-purple` `#9945FF`, `sol-magenta` `#DC1FFF`, `sol-green` `#14F195`
- Background `#0B0B0F`, foreground `#F5F5F2`

Fonts use Inter + JetBrains Mono via `next/font/google`. The licensed brand font (Diatype)
is paid; swap into `src/app/layout.tsx` if a license is available.

## Build (for offline backup)

```bash
pnpm build && pnpm start --port 3000
```

Static export of all slides ships in `.next` — every slide prerenders, so a backup PDF can
be generated by Playwright if needed.
